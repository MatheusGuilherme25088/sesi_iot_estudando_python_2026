# Estudando Python

Lista de exercícios de Python resolvida em aula do SESI SENAI no curso Técnico em Desenvolvimento de Sistemas.

## Tecnologias

- Python
- VsCode

## Arquivos

| Arquivo | Descrição |
|---|---|
| `hello.py` | Olá mundo |
| `soma.py` | Soma de dois números inteiros |
| `condicional.py` | Par ou ímpar (exemplo) |
| `for.py` | Números de 1 a 100 |
| `ex01_media.py` | Média de três números |
| `ex02_temperatura.py` | Conversor Celsius → Fahrenheit |
| `ex03_par_impar.py` | Número par ou ímpar |
| `ex04_fatorial.py` | Cálculo de fatorial |
| `ex05_bissexto.py` | Verificador de ano bissexto |
| `ex06_positivo_negativo.py` | Positivo, negativo ou zero |
| `ex07_comparacao.py` | Maior entre dois números |
| `ex08_idade.py` | Maior ou menor de idade |
| `ex09_triangulo.py` | Classificação de triângulos |

## Para testar

```bash
python nome_arquivo.py
```

Exemplo:

```bash
python ex04_fatorial.py
```
